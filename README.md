# Food and Nutrition Tracker

A Java program that helps users keep track of their daily meals, calories, and nutritional information.

## The Problem

It is challenging to keep track of how many calories and nutrients you consume throughout the day, especially if you eat out a lot. My project aims to make this easier by allowing users to search for foods, log their meals, and view their daily nutritional totals in one place.

## How It Works

The program will allow users to:

- Search for foods using the USDA FoodData Central API.
- View calories, protein, carbohydrates, and fats for different foods.
- Log foods under breakfast, lunch, dinner, or snacks.
- Save and load meal information using JSON files.
- Calculate total daily calories and macronutrients.
- Set daily calorie goals and view their progress.

The program will retrieve nutritional information from the USDA API and store meal logs locally.

## Tech Stack

- **Language:** Java
- **API:** USDA FoodData Central API
- **Library:** Jackson for JSON processing
- **Data Storage:** Local JSON files
- **Version Control:** Git and GitHub

## Setup

The project is currently in the planning stage. Once implemented, users will need Java installed and access to the USDA FoodData Central API. Setup instructions will be provided as development progresses.

## Usage

Users will be able to run the Java application, search for foods, log meals, and view their daily nutritional totals.
